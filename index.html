SmartTag QR Generator

Reproduces the app's rolling QR: builds the field string, RC4-encrypts it with the app's embedded key, hex-encodes the result and renders it at error-correction level M. Every field is editable — change the Android ID to generate a tag for any device.

Device

Random 16-char hex (64-bit), the Android ID format. Trimmed to the last 16 chars, or left-padded with x to 16.
STAD7dea3a7d7506a2eb

Time

Formatted yyyyMMddTHH:mm:ss.fff.
Off → the payload carries the literal token NST (no synced time).
App quirk preserved: negative offsets carry no sign.

Location

On only when GPS is enabled in the app; rounded to 6 decimals.

Generation

When on, LT and ST advance to the current time each tick, exactly as the running app regenerates its QR.
